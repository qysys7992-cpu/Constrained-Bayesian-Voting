# Results | 实验结果

本目录保存项目中由模型与实验程序产生的代表性结果数据。

This directory contains representative numerical outputs generated by the modeling and simulation pipeline.

主要包括：

- 潜在公众偏好推断结果
- 不同投票机制比较结果
- 特征影响分析结果
- 专业舞伴效应分析结果
- 综合实验统计结果

这些结果用于支持模型比较、可视化和敏感性分析。

The files in this directory are processed experimental outputs rather than raw competition data.
